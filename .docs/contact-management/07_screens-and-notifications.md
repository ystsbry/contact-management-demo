# 画面・ステータス遷移・通知

## 画面一覧

| パス | 内容 | 権限 |
|---|---|---|
| `/login` | ログイン。初回の本パスワード設定、パスワード再設定もここから | 誰でも |
| `/` | ダッシュボード。未対応件数、要返信件数、自分の担当件数、直近 10 件 | 担当者以上 |
| `/inquiries` | 一覧。絞り込み（ステータス、種別、担当者、要返信）、キーワード検索、ページング | 担当者以上 |
| `/inquiries/INQ-000123` | 詳細。お客様情報、ステータス・担当者の変更、タイムライン、返信フォーム、メモフォーム、同一メールの過去問い合わせ | 担当者以上 |
| `/settings/categories` | 種別マスタ | 管理者 |
| `/settings/users` | ユーザー管理 | 管理者 |
| `/settings/mail` | 送信元表示名、自動返信、通知先、署名 | 管理者 |
| `/account` | 自分のパスワード変更 | 本人 |

SPA なので CloudFront の 403 / 404 を `index.html` に書き換えて配信する。管理者限定の画面はサイドバーからロールに応じて出し分け、API 側でも拒否する。

## 各画面の要点

ダッシュボード:

- 件数カードを 3 つ（未対応、要返信、自分の担当）。クリックで該当の絞り込み付き一覧へ。
- 直近 10 件を一覧と同じ行形式で表示。

一覧:

- 行には受付番号、受付日時、氏名、種別、ステータス、担当者、「要返信」バッジ。
- 絞り込みは URL のクエリに持ち、ブラウザバックで復元できる。
- ページングは「次へ」のみ（カーソル方式）。

詳細:

- 上部にお客様情報とステータス・担当者のセレクト。変更は即時保存。
- タイムラインは古い順。メッセージは送受信で色を分け、内部メモとイベントは控えめに表示。
- 受信メッセージはテキスト本文のみ表示。添付があれば「添付 n 件（原本を保管、MVP では表示しない）」と出す。
- 返信フォームは本文のみ。件名は `[INQ-000123] Re: {元の件名}` で固定。送信前に確認ダイアログ。
- メモフォームは本文のみ。
- 同一メールアドレスの過去の問い合わせを下部に一覧。

設定:

- 種別: 名称、表示順、有効/無効の編集。削除はしない（既存の問い合わせが参照するため）。
- ユーザー: 追加すると Cognito から招待メールが届く。無効化、ロール変更、パスワードリセット。
- メール: 送信元表示名、自動返信の件名と本文（プレースホルダの説明付き）、通知先アドレス、署名。

## ステータス遷移

| 現在 | きっかけ | 次 |
|---|---|---|
| 未対応 | 担当者アサイン | 対応中 |
| 未対応 / 対応中 | スタッフが返信送信 | 返信済み |
| 返信済み / 完了 | お客様の返信を受信 | 対応中（担当者あり）/ 未対応（担当者なし） |
| 任意 | 手動変更 | 任意 |

- 完了にすると `closedAt` を記録する。
- 手動変更とアサインは、同じ問い合わせを別のスタッフが同時に更新した場合に備えて `updatedAt` を条件にした条件付き更新を行い、競合したら 409 を返す。

## 通知メール

送信元は `support@example.com`、宛先はスタッフ。

| イベント | 宛先 | 件名 |
|---|---|---|
| 新規問い合わせ | 通知先アドレス | `[新規] INQ-000123 {種別} {氏名}` |
| 担当者アサイン | 担当者 | `[担当] INQ-000123 があなたに割り当てられました` |
| お客様返信 | 担当者（未割当なら通知先） | `[返信あり] INQ-000123 {氏名}` |

本文には本文冒頭 200 文字と詳細画面 URL（`{APP_URL}/inquiries/INQ-000123`）を入れる。
